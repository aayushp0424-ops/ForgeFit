# ForgeFit

ForgeFit is a mobile-first nutrition and workout tracking application built using Next.js, React, and TypeScript.

This repository is being initialized with ForgeFit v0.4 (Feature Expansion).

Features include meal tracking, recipes, water and steps, progress analytics, and a pantry-constrained Meal Coach. Development remains a prototype: local browser storage, no authentication or cross-device synchronization, and no native HealthKit integration yet.
